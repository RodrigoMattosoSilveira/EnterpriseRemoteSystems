Pattern to submits patches:
1. a description of the error or of the change, 
2 A reference to a patch file which I click to download into my ~/Downloads folder
3. the git apply --check, to validate that the patch will integrate in my local issue branch
4. the git apply to integrate the patch in my local issue branch
5. a brief description of how you fixed the error or of the enchancement
6. A description of the tests you executed. Thanks for adhering this the pattern
